# Programming Activities

This folder contains the programming assignments and Program 7's September 16 rain-drop sensor data.

- `Program1.py`: Made September 9; prints "Hello world."
- `Program2.py`: Made September 9; prints "My Name is Anna Zheng."
- `Program3.py`: Made September 9; prints "My Name is Anna Zheng" using a string.
- `Program4.py`: Made September 9; blinks an LED.
- `Program5.py`: Made September 14; blinks an LED using a switch.
- `Program6.py`: Made September 16; controls a servo arm using a switch.
- `Program7.py`: Made September 16; reads ADC values and saves voltage data to a CSV file.

These CSV files contain Program 7 rain-drop sensor readings collected under different conditions, from a completely dry sensor to one covered with a wet wipe.

- `Trial1.csv`: Program 7 data with the rain-drop sensor completely dry.
- `Trial2.csv`: Program 7 data with air blown onto the rain-drop sensor.
- `Trial3.csv`: Program 7 data with half of the rain-drop sensor surface wiped with a wet wipe.
- `Trial4.csv`: Program 7 data after the entire rain-drop sensor surface was wiped down.
- `Trial5.csv`: Program 7 data with a wet wipe placed over the entire rain-drop sensor surface.

- `ENGR 095 - 9_16.xlsx`: Supporting data for the September 16 activity.
